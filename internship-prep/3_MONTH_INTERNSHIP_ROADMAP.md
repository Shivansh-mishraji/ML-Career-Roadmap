# 📚 3-Month Internship Preparation: The Strong Contender

**Target Audience:** You have 90 days. This is the optimal time to prepare for top-tier internships.
**Goal:** Deep mathematical understanding, advanced ML techniques, 3 deployed projects, and rigorous Data Structures & Algorithms (DSA) prep.

> [!TIP]
> **Mentor Reality Check:** Top companies (FAANG, elite startups) will test your algorithmic coding skills (LeetCode) alongside your ML knowledge. With 3 months, you must balance ML portfolio building with daily DSA practice.

---

## 🗓️ Month 1: Math, Python, and SQL (The Bedrock)

### Weeks 1-2: Mathematics & Python Mastery
- **Math:** Linear Algebra (Matrix multiplication, Eigenvectors), Calculus (Partial derivatives, Gradients), Probability (Bayes Theorem, Distributions).
- **Python:** Advanced Pandas, vectorization, list comprehensions, writing modular object-oriented code.
- **DSA Habit Starts:** Do 1 LeetCode problem (Easy/Medium) every single day. Focus on Arrays and Hash Maps.

### Weeks 3-4: Advanced SQL & Exploratory Data Analysis
- **SQL Mastery:** Subqueries, CTEs, Window Functions (`ROW_NUMBER`, `RANK`), Performance tuning.
- **EDA:** Handling missing data intelligently (Iterative Imputer), Feature Engineering (Polynomial features, Binning).
- **Action Item:** Build a comprehensive EDA notebook on a complex dataset (e.g., House Prices with 80+ features) and publish it to Kaggle.

---

## 🗓️ Month 2: Machine Learning & Deep Learning Foundations

### Weeks 5-6: Supervised & Unsupervised Learning
- **Algorithms:** Deep dive into how they work under the hood. Derive Linear Regression using Ordinary Least Squares. Understand the exact loss functions for XGBoost vs. Random Forest.
- **Unsupervised:** K-Means, DBSCAN, PCA (Dimensionality Reduction).
- **Action Item:** Build **Project 1** (Tabular Data) from the [Real-Time Projects Guide](./REAL_TIME_PROJECTS.md).

### Weeks 7-8: Deep Learning Foundations (PyTorch)
- **Concepts:** Build a Multi-Layer Perceptron (MLP) from scratch using NumPy to understand backpropagation, then switch to PyTorch.
- **Architectures:** Understand CNNs (for images) and RNNs (for sequential data).
- **Action Item:** Build an image classifier or a time-series forecasting model using PyTorch.

---

## 🗓️ Month 3: Modern NLP, Deployment, and Interview Polish

### Weeks 9-10: NLP & Generative AI
- **Concepts:** Tokenization, Embeddings, Attention Mechanism, Transformers.
- **GenAI:** Retrieval-Augmented Generation (RAG), Vector Databases (ChromaDB), LLM APIs.
- **Action Item:** Build **Project 2** using our [RAG Template](../interactive-projects/RAG_LLM_TEMPLATE.md).

### Week 11: Deployment (MLOps)
- **Concepts:** FastAPI, Docker, Cloud Platforms (AWS EC2 / Render).
- **Action Item:** Deploy your best model to a live web endpoint. Document the API using Swagger (built into FastAPI).

### Week 12: Interview Mastery
- **Mock Interviews:** Use platforms like Pramp or Interviewing.io for mock technical screens.
- **DSA Polish:** Ensure you are comfortable with Trees, Graphs, and basic Dynamic Programming.
- **Resume & Outreach:** Finalize your resume. Send targeted cold emails with links to your live, deployed projects. (See [Networking Tips](./MENTOR_TIPS_AND_NETWORKING.md)).
