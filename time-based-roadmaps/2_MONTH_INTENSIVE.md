# 🔥 2-Month Intensive: The Portfolio Builder

**Target Audience:** You have 60 days. This is enough time to go beyond the basics, understand *why* models work, and build a standout portfolio that gets you past the resume screen.
**Goal:** Strong ML fundamentals, basic Deep Learning knowledge, and 2-3 end-to-end projects.

> [!IMPORTANT]
> **Depth Expectation:** You have time to understand Hyperparameter tuning, Cross-Validation, and basic Neural Network architectures. You should know the math behind Gradient Descent conceptually, but don't worry about proving theorems.

---

## 🛠️ What to Prepare (Topics)
1. **Advanced Python:** Vectorization (NumPy), Data Cleaning pipelines.
2. **Machine Learning:** Regression, Classification, Clustering (K-Means), PCA, Ensemble Methods.
3. **Deep Learning Intro:** Basic Neural Networks (PyTorch or Keras).
4. **Tooling:** Git/GitHub, basic Docker.

## 📚 From Where to Prepare (Resources)
- **Machine Learning:** [Andrew Ng's Machine Learning Specialization](https://www.coursera.org/specializations/machine-learning-introduction) (Coursera). *Watch on 1.5x speed.*
- **Deep Learning Practical:** [Fast.ai Practical Deep Learning](https://course.fast.ai/). Focus on Lessons 1-4.
- **Projects:** Use our [Real-Time Projects Guide](../internship-prep/REAL_TIME_PROJECTS.md).

---

## 🗓️ 8-Week Breakdown

### Weeks 1-2: Data Engineering & EDA
- **How:** Master Pandas and Seaborn.
- **Depth:** Learn to identify outliers, handle skewed distributions, and perform feature scaling (StandardScaler vs MinMaxScaler).
- **Action:** Take a messy dataset from Kaggle, perform a full Exploratory Data Analysis, create 5+ visual insights, and publish a notebook.

### Weeks 3-4: Classical Machine Learning
- **How:** Focus on Scikit-Learn pipelines and Cross-Validation.
- **Depth:** Understand the mathematical intuition behind Logistic Regression, SVMs, and XGBoost. Learn `GridSearchCV` for hyperparameter tuning.
- **Action:** Build **Project 1** (e.g., Customer Churn Prediction). Implement a robust cross-validation strategy.

### Weeks 5-6: Deep Learning & NLP Fundamentals
- **How:** Dive into unstructured data (text or images).
- **Depth:** Understand how an Embedding works. Learn what a CNN or a basic Transformer does at a high level.
- **Action:** Build **Project 2** (e.g., AI Resume Screener). Use HuggingFace `transformers` to classify text or match documents. 

### Weeks 7-8: Deployment & Interview Prep
- **How:** A model is useless if it lives in a Jupyter notebook.
- **Depth:** Learn how to wrap a model in an API. You don't need to be a Kubernetes expert, but you must know Docker basics.
- **Action:** Use our [MLOps Deployment Template](../interactive-projects/MLOPS_DEPLOYMENT_TEMPLATE.md) to serve Project 1 via FastAPI. Polish your GitHub READMEs and start applying.
